# 01 模型与公式（软著 V1.0 口径）

> 适用：抽水蓄能—火电深度调峰协同的**日尺度确定性核算**。
> 对应 MATLAB：`evaluate_objective.m`、`tanpafangjisuan.m`、`process.m`、`main.m`。
> 版本：`1.0.0`。本文件的所有公式均已在 Python 中复刻，并与 `AA.mat` 逐日结果对齐。

## 1. 符号与单位

| 符号 | 含义 | 单位 |
|---|---|---|
| `L(t)` | 负荷 | MW |
| `Nh(t)` | 水电出力 | MW |
| `Nw(t)` | 风电出力 | MW |
| `Np(t)` | 光伏出力 | MW |
| `Npump(t)` | 抽蓄功率，正=发电，负=抽水 | MW |
| `Nt(t)` | 火电出力 | MW |
| `Zpump` | 抽蓄装机 | MW |
| `h` | 蓄能时长 | h |
| `V = Zpump·h` | 蓄能容量 | MWh |
| `C(t)` | 储能状态 SOC，0~1 | — |
| `η` | 抽发综合效率 | — |
| `H` | 供电煤耗 | g/kWh |
| `Ce` | 排放强度 | g/kWh |
| `Emi` | 排放量 | kg/h |

**关键换算**：`1 MW × 1 h = 1 MWh`；`Ce(g/kWh) × Nt(MW) = kg/h`；24 小时求和为 `kg/d`；`1 万吨 = 1e7 kg`。

## 2. 功率平衡

有抽蓄：

```
Nt(t) = L(t) - Nh(t) - Nw(t) - Np(t) - Npump(t)
```

无抽蓄：

```
Nt2(t) = L(t) - Nh(t) - Nw(t) - Np(t)
```

新能源合计 `N(t) = Nh(t) + Nw(t) + Np(t)`。

## 3. SOC 与抽蓄功率

给定 25 点 SOC：`C(1)=0.5`，`C(25)=0.5`，`C(2..24)` 为 23 个决策变量。

发电（`C(i+1) <= C(i)`）：

```
Npump(i) = (C(i) - C(i+1)) × V
```

抽水（`C(i+1) > C(i)`）：

```
Npump(i) = (C(i) - C(i+1)) × V / η      # 结果为负
```

约束与死区（与 MATLAB 一致）：

- `|Npump| < 0.2 × Zpump` 时置 0，SOC 回退到上一时刻；
- `Npump > Zpump` 时限幅为 `Zpump`；
- `Npump < -Zpump` 时限幅为 `-Zpump`；
- 首末 SOC 应为 0.5。原 MATLAB 优化模型会把不满足该条件的解判为不可行（惩罚 `999999999999`）；本核算工具对这类输入会给出警告并继续核算，结果只能作情景参考，不能当作优化解。

## 4. 调峰深度

```
Zt_f = (max(Nt) - min(Nt)) / 0.7
```

`Zt_f` 是火电调峰容量（MW）。若 `Zt_f > max(Nt)`，则基荷 `Nt_b = 0`；否则：

```
Nt_b = max(Nt) - Zt_f
```

参与排放计算的调峰出力：

```
TH(t) = Nt(t) - Nt_b
THmax = Zt_f
```

## 5. 三段煤耗

| 区间 | 煤耗 H | 说明 |
|---|---|---|
| `TH < 0.4·THmax` | 370 g/kWh | 深度调峰 |
| `0.4·THmax ≤ TH < 0.5·THmax` | 330 g/kWh | 中度调峰 |
| `TH ≥ 0.5·THmax` | 300 g/kWh | 基荷/高负荷 |

注意：计算前先把 `TH` 下限抬到 `0.3·THmax`：

```
TH_eval = max(TH, 0.3 × THmax)
```

这是原模型的防负值处理，也意味着**深度调峰段存在一个平台**。

## 6. 排放强度

### 6.1 基本排放

```
Ce1 = H × OF × Cc × 44/12
```

`OF=0.99`（碳氧化率），`Cc=0.70`（含碳量），`44/12=3.6667`。

### 6.2 效率与厂用电损失（仅 370/330 段）

```
Ce2 = H × (1 - e/e100) × Cq
    + H × (1 - g/g100) × Cq
    + a × H × Cq
```

| 参数 | 100% | 50% | 40% | 30% |
|---|---|---|---|---|
| 锅炉效率 `e` | 0.953 | 0.934 | 0.920 | 0.904 |
| 汽轮机效率 `g` | 0.458 | 0.442 | 0.424 | 0.401 |

`Cq=0.9183`（单位质量燃料的 CO2 系数），`a=0.02`（厂用电占比）。
`e`、`g` 在 30%~40% 与 40%~50% 区间内**线性插值**；`TH ≥ 0.5·THmax` 时 `Ce2=0`。

### 6.3 脱硫与辅助过程（仅深度调峰段）

```
Ce3 = H × ps × us × 44/32
    + H × as × Cq
    + H × ys × Cq
```

`ps=0.01`（燃煤含硫率），`us=0.95`（脱硫效率），`Ms=32`；`as=0.0148`、`ys=0.00392`（脱硫/石灰石能耗比）。

### 6.4 小时排放

```
Ce(t) = Ce1 + Ce2 + Ce3
Emi(t) = Ce(t) × TH_eval(t) + Emi_b
Emi_b = 300 × OF × Cc × 44/12 × Nt_b
```

`Emi_b` 是基荷部分的排放（kg/h），对每个小时都加一次。

日排放：

```
Emi_day = Σ Emi(t)          # kg/d
```

## 7. 减碳量

```
ΔEmi = Emi_without - Emi_with      # kg/d
减排率 = ΔEmi / Emi_without × 100  # %
全年减碳 = Σ ΔEmi / 1e7            # 万吨
```

## 8. 数值校验

用 `AA.mat` 中 365 天的 NSGA-II 折中解逐日复算，Python 与 MATLAB 的 `f1`（Zt_f）和 `f2`（日排放）按 3 位小数一致，最大绝对误差小于 0.001；下列为 6 个样本日：

| 日序 | Zt_f (MW) | 日排放 (kg) |
|---|---|---|
| 1 | 8598.040873 | 461,198,347.900 |
| 2 | 11317.482253 | 446,218,772.868 |
| 3 | 12855.999414 | 444,560,078.856 |
| 100 | 11499.921431 | 290,372,463.795 |
| 201 | 13210.912044 | 434,137,578.807 |
| 365 | 18446.329805 | 434,080,010.005 |

全年汇总：**897,883.4 t = 89.7883 万吨**，减排率 **0.6425%**。

## 9. 模型的一个必须说明的特性

煤耗在 `0.4·THmax`、`0.5·THmax` 处是**阶跃**的：输入数据只差 0.005 MW，也可能让某一小时从 330 跳到 370 g/kWh，导致日减碳量差几百吨。

因此：

1. 不要把 2 位小数的数据与 6 位小数的数据混用；
2. 不要对小于 0.1% 的差异做过度解读；
3. 做敏感性分析时，关注“是否跨段”，而不是只看连续斜率。

## 10. 适用边界

- 日尺度、1 h 步长；不适用于秒级机电暂态；
- 只算 CO2 物理排放，不含 CH4/N2O，不直接等于 CCER 签发量；
- 火电按统一煤耗曲线，未分机组类型；
- 抽蓄效率、死区为固定参数，未考虑水头变化与辅助服务损耗。
