# 02 参数与口径

## 1. 默认工况（软著 V1.0）

| 参数 | 字段名 | 默认值 | 单位 | 建议范围 |
|---|---|---|---|---|
| 抽蓄装机 | `zpump_mw` | 1400 | MW | 100–3000 |
| 蓄能时长 | `duration_h` | 4 | h | 2–12 |
| 抽发综合效率 | `efficiency` | 0.75 | — | 0.70–0.80 |
| 最小出力比例 | `min_load_ratio` | 0.20 | — | 0.10–0.30 |
| 碳氧化率 | `oxidation_factor` | 0.99 | — | 0.95–1.00 |
| 收到基含碳量 | `carbon_content` | 0.70 | — | 0.55–0.75 |
| 深度调峰煤耗 | `coal_deep_g_per_kwh` | 370 | g/kWh | 350–400 |
| 中度调峰煤耗 | `coal_mid_g_per_kwh` | 330 | g/kWh | 310–350 |
| 基荷煤耗 | `coal_base_g_per_kwh` | 300 | g/kWh | 280–320 |

派生量：

```
V = zpump_mw × duration_h          # MWh
最大抽水/发电功率 = zpump_mw        # MW
死区功率 = zpump_mw × min_load_ratio
```

## 2. 软件面板里的“8 类核心参数”

软著用户手册列出 8 类可调参数：抽蓄装机规模、扬程高度（蓄能时长）、抽发效率、最小出力比例、碳排放因子、高/中/低负荷煤耗率。对应到本 SKILL：

- `zpump_mw`、`duration_h`、`efficiency`、`min_load_ratio`；
- `oxidation_factor` 与 `carbon_content` 共同决定“碳排放因子”；
- `coal_deep_g_per_kwh`、`coal_mid_g_per_kwh`、`coal_base_g_per_kwh`。

软件内置“默认方案 / 高消纳方案 / 深度低碳方案 / 灵活调峰方案”四套预设；预设的具体数值以软件内为准，本文件不擅自复制。

## 3. 参数怎么选

### 3.1 装机与时长

- 装机 `Zpump` 决定最大调节功率；时长 `h` 决定能量容量 `V`。
- 二者共同决定“能搬多少能量”：`V = Zpump × h`。
- 同样 `V` 下，大功率短时长适合削峰，小功率长时长适合平移。

### 3.2 效率

- 0.75 是软著默认值，属于偏乐观的工程值；
- 实际抽蓄“抽水—发电”循环效率常见 0.70–0.80，老旧机组可低至 0.65；
- 效率越低，抽水耗电越多，减碳量越容易被抵消，甚至为负。

### 3.3 死区

- 20% 死区意味着小于 280 MW（1400 MW 机组）的动作不执行；
- 死区越大，调度越“粗”，可执行的调节时段越少；
- 做敏感性分析时，死区是最容易出现“结果跳变”的参数之一。

### 3.4 煤耗三段

- 370/330/300 是软著内置值，反映“深度调峰—中度调峰—基荷”的煤耗差异；
- 不同机组类型（超超临界、亚临界、循环流化床）差异很大；
- 若用户有电厂实际煤耗曲线，应替换三段值，并在报告中注明来源。

### 3.5 碳氧化率与含碳量

- `OF=0.99`、`Cc=0.70` 是软著内置值；
- 这两个参数直接乘在 `Ce1` 上，对结果影响接近线性；
- 不同煤种（无烟煤、烟煤、褐煤）含碳量差异明显，跨煤种比较时必须改。

## 4. 数据要求

| 数据 | 格式 | 要求 |
|---|---|---|
| 负荷 | 24 个数/日，MW | 非负；建议与实际调度口径一致 |
| 水电 | 24 个数/日，MW | 非负；含径流式/调节式分别注明 |
| 风电 | 24 个数/日，MW | 非负；弃风是否扣减要说明 |
| 光伏 | 24 个数/日，MW | 非负；是否含分布式要说明 |
| SOC | 25 个数/日，0–1 | 首末均为 0.5；不提供则用启发式 |

**不要**把“万 kW”“GW”“kWh/日”“MWh”直接填进 MW 字段。单位错 1000 倍，结果会错得离谱。

## 5. 参数敏感性（定性）

| 参数 | 对减碳量的影响 | 备注 |
|---|---|---|
| `efficiency` ↑ | 减碳量 ↑ | 抽水耗电减少，最敏感之一 |
| `min_load_ratio` ↑ | 可执行动作减少，减碳量可能 ↓ | 容易出现零动作 |
| `zpump_mw` ↑ | 调节能力 ↑，但抽水耗电也 ↑ | 存在最优规模 |
| `duration_h` ↑ | 能量容量 ↑，可跨时段平移 | 受水库条件约束 |
| `coal_deep` ↑ | 深度调峰排放 ↑，替代收益 ↑ | 与 Base 的差值决定减碳 |
| `coal_base` ↑ | 无抽蓄基线排放 ↑，减碳量 ↑ | 基线越脏，抽蓄越“划算” |

## 6. 结果口径

- 本工具算的是**运行阶段 CO2 物理排放**，不含建设、退役、设备制造；
- 不包含 CH4、N2O；
- 不直接等于 CCER 可签发量：CCER 还需要额外性论证、基线识别、监测计划与第三方审定；
- 负减碳量是模型允许的输出，代表“本日抽蓄不划算”，不是程序错误。
