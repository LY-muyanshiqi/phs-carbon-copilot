# 蓄能碳效参谋 · 一页纸方案

## 一句话

把抽水蓄能减碳核算从“填参数、等结果、看不懂”变成“说需求、拿结论、能追溯”的智能体。

## 问题

抽水蓄能到底减多少碳，取决于抽水时段、电源结构、机组效率、调峰深度，不是一个固定系数能算出来的。现有工具要么是黑箱软件，要么要求用户自己写 MATLAB；科研人员和电站前期人员往往卡在“参数怎么取、结果怎么解释、报告怎么写”。

## 方案

**一个智能体 + 一个可执行 SKILL + 一套知识库。**

- 智能体负责问清对象、装机、时长、效率、数据口径；
- SKILL 负责确定性核算：有/无抽蓄两种情景、逐时功率、排放强度、减碳量；
- 知识库负责解释模型、参数、FAQ 与边界，避免“一本正经地胡说”。

## 演示脚本（3 分钟）

1. **0:00** 用户：“示例：某 1400 MW / 4 h 抽蓄，帮我算 11 月 17 日减多少碳。”
2. **0:20** 智能体列出缺项：负荷、水/风/光 24 点、SOC。
3. **0:50** 用户给数据；智能体校验单位与长度，调用工具。
4. **1:30** 返回：减碳 **9,547.8 t**，减排率 **2.30%**；有抽蓄 40.57 万 t，无抽蓄 41.53 万 t；平均排放强度 791.6 → 769.6 g/kWh。
5. **2:10** 用户追问“为什么负值/能不能用于 CCER”，智能体按知识库解释边界。
6. **2:40** 一键出报告：结论、口径、结果表、假设、风险提示。

## 差异化

| 常见做法 | 本作品 |
|---|---|
| 直接给一个减排系数 | 逐时功率平衡，算到 24 点 |
| 只做问答 | 问答 + 可执行核算工具 |
| 结果不可追溯 | 参数、公式、版本、警告全留痕 |
| 只算单日 | 单日 / 多日 / 全年 8760 小时 |
| 把启发式当最优 | 明确区分“优化解”与“演示调度” |

## 已验证的硬指标

- 与软著 MATLAB `AA.mat` 365 天逐日复算：3 位小数一致（最大误差 <0.001，6 个样本日列出）；
- 全年 365 天：**897,883.4 t = 89.7883 万吨**，减排率 0.6425%；
- 全年计算 **约 0.12 s**；
- 自动化评测 **20/20 通过**，覆盖缺字段、长度错、负值、参数越界、SOC 异常等错误；
- 单日最佳样本：**+9,547.8 t**。

## 适用与不适用

**适用**：抽蓄方案比选、火电深度调峰减碳测算、科研论文的算例、课程/竞赛教学。

**不适用**：实时调度、机组控制、机电暂态、CCER 签发、投资决策。
