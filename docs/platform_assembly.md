# 平台装配说明

> 目标：把本地已经跑通的“核算核心 + SKILL”接到 SCNet 智能体平台，形成一个能演示、能问答、能出结果的智能体。
> 说明：不同版本的平台菜单名称可能不同，下面按“字段/动作”描述，不绑定具体按钮。

## 0. 前置检查

```bash
cd phs-carbon-copilot/skills/pumped-storage-carbon
python cli.py --demo
```

能看到“减碳量 9,547.8 t”再往下做。

## 1. 启动工具服务

### 方式 A：本机（最快，适合录制 Demo）

```bash
python http_server.py --port 8790
```

自检：

```bash
curl http://127.0.0.1:8790/health
# {"ok": true, "method_version": "1.0.0"}
```

### 方式 B：集群/公网（平台无法访问本机时）

把 `skills/pumped-storage-carbon/` 整个目录上传到 SCNet 集群存储，用便携脚本作业启动：

```bash
cd /path/to/pumped-storage-carbon
python3 http_server.py --host 0.0.0.0 --port 8790
```

注意：

- 端口需要在平台/集群侧可访问；不确定时先问活动技术群。
- 不要把含真实项目数据的 `data/raw/`、`data/local/` 一起上传。
- 服务只读计算，不写数据库，不保存请求。

## 2. 创建智能体

| 字段 | 填入 |
|---|---|
| 名称 | 蓄能碳效参谋 |
| 一句话简介 | 会算、会解释、会出报告的抽水蓄能减碳核算智能体 |
| 系统提示词 | `agent/system_prompt.md` 全文 |
| 知识库 | `agent/knowledge/01_model.md`、`02_parameters.md`、`03_faq.md`、`04_boundaries.md` |
| 开场白 | “我是蓄能碳效参谋。告诉我核算对象、装机与时长、以及 24 小时负荷/风光数据，我帮你算有/无抽蓄的减碳量。” |
| 推荐问题 | ① 1400 MW / 4 h 抽蓄，效率 0.75，一天能减多少碳？② 为什么减碳量会是负的？③ 这个结果能用于 CCER 吗？ |

知识库上传后，用平台的分段/向量化设置保留标题层级；`01_model.md` 的公式段落不要切得太碎。

## 3. 添加工具

| 字段 | 填入 |
|---|---|
| 工具名 | `carbon_calculate` |
| 类型 | HTTP / 自定义 API |
| 方法 | POST |
| URL | `http://127.0.0.1:8790/calculate`（或集群地址） |
| 超时 | 30 s（全年 365 天约 0.1–0.2 s，留足余量） |
| 请求 Schema | `agent/tool_schema.json` |
| 响应 | JSON，`ok=true` 时读 `summary` 与 `days` |

如果平台只支持“函数/本地脚本”而不支持 HTTP，把 `cli.py` 注册为脚本工具，入参用临时 JSON 文件，出参读 stdout。

## 4. 验收对话（发布前必跑）

1. “1400 MW、4 小时、效率 0.75，算 2026-11-17 的减碳量。”
   - 期望：先要数据；给示例后返回 9,547.8 t、2.30%。
2. “没有 SOC 能算吗？”
   - 期望：能，但明确说“启发式、非最优”。
3. “为什么是负的？”
   - 期望：解释抽水耗电、高煤耗补足、损耗。
4. “能直接用于 CCER 吗？”
   - 期望：不能，说明额外性/方法学/审定。
5. “光伏少给一个点行不行？”
   - 期望：拒绝，提示 `E_LENGTH`，要求 24 点。

任何一条出现“编数字”“把启发式说成最优”“承诺 CCER”，先改提示词再发布。

## 5. 发布材料清单

- 智能体链接/二维码；
- `docs/one_pager.md` 导出 PDF；
- 3–5 分钟 Demo（建议按第 4 节顺序录）；
- 实践报告 6 页（PDF/DOCX）；答辩 PPTX 10 页；
- 算力证据：作业 ID、队列、核时、结果文件截图（若平台作业未跑通，如实写“本地验证”）。

## 6. 常见故障

| 现象 | 排查 |
|---|---|
| 工具 404 | URL 少了 `/calculate`，或服务没启动 |
| 工具 422 | 看 `error.code`：`E_LENGTH` 补 24 点；`E_RANGE` 查负值；`E_PARAM` 查参数范围 |
| 平台访问不到 127.0.0.1 | 平台在远端，改用集群地址或公网隧道 |
| 中文乱码 | 终端执行 `chcp 65001`；结果文件本身是 UTF-8 |
| 全年很慢 | 确认没有逐日重复启动进程；单进程 365 天约 0.1–0.2 s |

## 7. 安全

- 服务默认绑定 `127.0.0.1`，不要直接暴露到公网；
- 不记录请求体，不落盘用户数据；
- 演示用示例数据，真实数据脱敏；
- 平台知识库只放方法文档，不放原始数据。
